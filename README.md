A modern and interactive **E-Commerce Sales Dashboard** built using **Power BI** to analyze sales performance, profits, regional trends, and category insights through a luxury black-gold themed business intelligence interface.

---

# 📌 Project Overview

This dashboard provides a complete overview of e-commerce business performance with visually rich analytics and interactive filtering options.

The project focuses on:

* Sales Analysis
* Profit Tracking
* Regional Performance
* Category Insights
* Business Growth Trends

---

# 🚀 Dashboard Features

✔ Interactive KPI Cards
✔ Year-wise Sales & Profit Analysis
✔ Top Performing Cities by Sales
✔ Profit Distribution by Category
✔ Regional Sales Analysis
✔ Interactive Matrix Table
✔ Dynamic Filters & Slicers
✔ Premium Black-Gold UI Design

---

# 📊 Key Insights

* Sales and profits steadily increased from 2014–2017
* California generated the highest sales revenue
* Technology category contributed the highest profits
* West region showed the strongest business performance
* Overall business growth remained positive across all years
